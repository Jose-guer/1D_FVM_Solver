# 1D_FVM_Solver
MATLAB implementation of a first-order accurate, one-dimensional, Finite Volume Method (FVM) solver with a Roe flux, for flows with area changes, friction, and chemical reactions.

## System requirements 
No specific version of MATLAB is required.

## Description of Code
The FVM solver is demonstrated for two examples. 

 - The first is a converging-diverging nozzle with friction and a shock in the diverging portion. In this example the specific heat ratio is constant and no chemical reactions are allowed.

 - The second is a combustor with a converging-diverging nozzle. In the combustor section chemical reactions are allowed.
